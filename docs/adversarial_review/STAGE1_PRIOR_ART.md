## Combination assessment

The existing workflow can be encoded as categorical source-choice variables, Boolean lineage for each observed predicate, a conjunctive query over context, and conditional queries after an oracle supplies metadata. P01–P08/P16 already provide its representation, certainty, compilation and resolution mechanisms; P09–P15/P18–P22 supply close claim-verification applications. We did not identify one source expressly reciting every implementation detail, but that is insufficient to establish novelty or inventive step. The earlier annex overstated the specificity of the remaining gap. Stage 2 must not promote this combination merely because it has a new name.
