# ScopeGuard synthetic engineering fixtures

300 examples generated by `python -m claimaudit.evaluation.scope_benchmark`: six families, 50 numerical parameter variations per family. No real-paper evidence, independent annotation, train/test split, or learned parameters. These are functional checks, not 300 independent scientific experiments.

Each line contains an ID, family, author-assigned expected status and a structured problem. The verifier receives only `problem`; expected statuses never enter its input. Every source locator is explicitly synthetic. Source-choice alternatives are mutually exclusive whole bundles; distinct blocks are independent. The six families are joint support, cross-experiment splicing, missing evidence, header ambiguity, exclusive-alternative splicing and invariant support.

The existing `data/controlled_v1` experiment remains separate. Do not combine accuracy from these different tasks into one score.
